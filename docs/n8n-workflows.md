# Сценарии n8n

Все сценарии работают в n8n Cloud, данные хранятся в PostgreSQL (Neon). Ошибки любого рабочего сценария обрабатывает «Монитор» (error workflow).

| Сценарий | Запуск | Узлы | Назначение |
| --- | --- | --- | --- |
| MyWay · Публикатор | Schedule Trigger, каждые 5 мин | Postgres (overdue) → Filter → Telegram; Postgres (claim, `FOR UPDATE SKIP LOCKED`) → Filter → Telegram sendMessage → Postgres (published + publish_log); ошибка → Postgres (повтор / failed) → IF → Telegram | Публикация одобренных постов, защита от двойной публикации и «залпа» просроченных постов, 3 попытки при ошибке |
| MyWay · Монитор | Error Trigger + Schedule 09:00 МСК | Error Trigger → Telegram; Schedule → Postgres (статистика) → Telegram | Тревога при сбое любого сценария; ежедневная сводка: вышло вчера, очередь на 7 дней, проблемные посты, ближайшие 3 дня |
| MyWay · Пульт | Telegram Trigger (message, callback_query), только Telegram ID автора | Code (разбор апдейта) → Switch → Postgres + Telegram answerQuery + sendMessage | Кнопки черновика «В ближайший слот» / «Удалить», команда /queue, справка |
| MyWay · Приём черновиков | Webhook, ручной запуск через MCP | Code (разбор) → Postgres (draft) → Telegram sendMessage с inline-клавиатурой | Принимает черновики от ИИ-автора и отправляет автору превью с кнопками |
| MyWay · Служебный: SQL-консоль | Webhook, только ручной запуск | Postgres executeQuery | Администрирование и чтение БД для ИИ-автора |
| MyWay · Служебный: создание БД и импорт очереди | Webhook, ручной запуск | Postgres (DDL) → Code → Postgres (insert) | Разовая миграция очереди из старой SQLite (13 постов) |

## ИИ-автор

Черновики пишет запланированная задача Claude (2 раза в день, 08:45 и 16:45 МСК):

1. читает через SQL-консоль посты за 21 день, чтобы не повторять темы;
2. изучает стиль канала по публичной ленте `t.me/s/my_way_finance`;
3. собирает свежие новости из 6 публичных Telegram-каналов (`t.me/s/...`);
4. пишет 1–2 черновика и передаёт их в «Приём черновиков» через n8n MCP.

Публикует только автор: черновик попадает в очередь лишь после нажатия кнопки «В ближайший слот».

## Правило выбора слота

Новость → 12:00 МСК, пост из плана → 19:05 МСК. Выбирается ближайший день (не раньше чем через 10 минут), на который ещё нет запланированного или опубликованного поста — не больше одного поста в день.
