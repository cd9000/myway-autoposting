# Сценарии n8n

Все сценарии работают в n8n Cloud, данные хранятся в PostgreSQL (Neon). Ошибки любого рабочего сценария обрабатывает «Монитор» (error workflow).

| Сценарий | Запуск | Узлы | Назначение |
| --- | --- | --- | --- |
| MyWay · Публикатор | Schedule Trigger, каждые 5 мин | Postgres (overdue) → Filter → Telegram; Postgres (claim, `FOR UPDATE SKIP LOCKED`) → Filter → IF (есть картинка и текст ≤ 1000 знаков) → Telegram sendPhoto по file_id / sendMessage → Postgres (published + publish_log); ошибка → Postgres (повтор / failed) → IF → Telegram | Публикация одобренных постов, защита от двойной публикации и «залпа» просроченных постов, 3 попытки при ошибке |
| MyWay · Монитор | Error Trigger + Schedule 09:00 МСК | Error Trigger → Telegram; Schedule → Postgres (статистика) → Telegram | Тревога при сбое любого сценария; ежедневная сводка: вышло вчера, очередь на 7 дней, проблемные посты, ближайшие 3 дня |
| MyWay · Пульт | Telegram Trigger (message, callback_query), только Telegram ID автора | Code (разбор апдейта) → Switch → Postgres + Telegram answerQuery + sendMessage | Кнопки черновика «В ближайший слот» / «Удалить», команда /queue, справка |
| MyWay · Приём черновиков v2 | Webhook, ручной запуск через MCP | Code (разбор) → Postgres (draft) → Postgres (автопланирование) → HTTP Request (генерация иллюстрации, Pollinations) → Code → IF → Telegram sendPhoto с кнопкой «Отменить» → Postgres (photo_file_id) | Принимает черновик, ставит его в ближайший свободный день, рисует картинку по теме и присылает автору превью с правом вето |
| MyWay · Служебный: картинки к постам в очереди | Webhook, ручной запуск | Code → HTTP Request (Pollinations, пауза 50 с из-за лимита бесплатного тарифа) → Filter → Telegram sendPhoto → Postgres | Догенерация иллюстраций к уже запланированным постам |
| MyWay · Служебный: SQL-консоль | Webhook, только ручной запуск | Postgres executeQuery | Администрирование и чтение БД для ИИ-автора |
| MyWay · Служебный: создание БД и импорт очереди | Webhook, ручной запуск | Postgres (DDL) → Code → Postgres (insert) | Разовая миграция очереди из старой SQLite (13 постов) |

## ИИ-автор

Черновики пишет запланированная задача Claude (2 раза в день, 08:45 и 16:45 МСК), не больше одного поста за запуск:

1. читает очередь через SQL-консоль и решает, что нужно: новость (сегодня или завтра пусто), пост из плана (свободный день в ближайшие 7 дней) или ничего;
2. изучает стиль канала по публичной ленте `t.me/s/my_way_finance`;
3. выбирает тему с наибольшими просмотрами в 6 публичных Telegram-каналах и проверяет факты по двум источникам;
4. пишет пост до 950 знаков (подпись к фото в Telegram ограничена 1024) и описание иллюстрации на английском (`image_prompt`);
5. передаёт черновик в «Приём черновиков v2» через n8n MCP.

Пост публикуется автоматически, у автора есть право вето: кнопка «Отменить» в превью действует до времени публикации.

## Иллюстрации

Картинку 1280×720 генерирует Pollinations по `image_prompt` при приёме черновика. Telegram возвращает `file_id` загруженного фото; он сохраняется в `posts.photo_file_id`, и публикатор отправляет фото повторно по этому `file_id` без новой генерации. Если текст длиннее 1000 знаков (лимит подписи к фото), в начало поста добавляется скрытая ссылка на картинку (`posts.image_url`) — Telegram показывает её крупным превью, а текст остаётся без сокращений. Если картинку получить не удалось, пост выходит текстом. Фото с подписью переходит в Дзен через кросспостинг вместе с постом.

## Правило выбора слота

Новость → 12:00 МСК (в пределах 2 дней), пост из плана → 19:05 МСК (в пределах 14 дней). Выбирается ближайший день не раньше чем через 60 минут, на который ещё нет запланированного или опубликованного поста — не больше одного поста в день.
