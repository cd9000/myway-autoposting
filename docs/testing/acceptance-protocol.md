## Замечания к следующей итерации

1. Включить авторизацию API приёма (`X-API-Key`) и прогнать TC-API-06.
2. Валидировать запрос по схеме OpenAPI на стороне n8n (сейчас проверяется только `body`).
3. Отдельный пользователь PostgreSQL с правами только на SELECT для SQL-консоли ИИ-автора.
4. Текст справки в пульте устарел («черновики приходят с кнопками “В ближайший слот” и “Удалить”») — обновить под автопланирование с правом вето.
5. US-2 в требованиях MVP-1 («текст длиннее 1024 уходит отдельным сообщением») не соответствует реализации ФТ-15 — актуализировать.
