# Тест-кейсы: подсистема черновиков и публикация

Покрытие требований [ЧТЗ](../requirements/tz-drafts.md) и [MVP-1](../requirements/mvp1-requirements.md). Результаты прогона — в [протоколе приёмки](acceptance-protocol.md).

**Окружение:** n8n Cloud, PostgreSQL (Neon), бот @myway_poster_bot, режим `live` (кроме TC-PUB-01). Тестовые посты помечаются «ТЕСТ» в первой строке и отменяются сразу после проверки.

**Приоритет:** В — без этого приёмка невозможна, С — важно, Н — желательно.
